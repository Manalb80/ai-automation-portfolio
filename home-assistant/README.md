# Home Assistant Configurations

Core HA configuration files — automations, dashboards, packages and templates.

## Structure

```
home-assistant/
├── automations/       # YAML automation files
├── dashboards/        # Lovelace dashboard configs
├── packages/          # Packaged configs by room/function
├── templates/         # Jinja2 sensor and notification templates
└── configuration.yaml # Main HA config (sanitised)
```
