# AI Automation Portfolio

Smart home and AI automation projects by **MB** — AI Automation Consultant specialising in Home Assistant, YAML-driven workflows, and connected living solutions.

## What's Inside

| Folder | Description |
|--------|-------------|
| `home-assistant/` | Home Assistant configurations, automations and dashboards |
| `blueprints/` | Reusable HA blueprints for common automation patterns |
| `integrations/` | Custom integration configs and API connectors |
| `scripts/` | Python and shell scripts for deployment and maintenance |
| `docs/` | Technical documentation, architecture notes and guides |

## Tech Stack

- **Platform:** Home Assistant (YAML + Python)
- **Protocols:** Zigbee, Z-Wave, Matter, Wi-Fi, MQTT
- **Dashboards:** Lovelace YAML, custom cards
- **Infrastructure:** Docker, Proxmox, Cloudflare Tunnels
- **Automation engines:** Node-RED, HA Automations, AppDaemon

## Getting Started

Each project folder has its own `README.md` with setup instructions. Clone the repo and explore:

```bash
git clone https://github.com/Manalb80/ai-automation-portfolio.git
cd ai-automation-portfolio
```
